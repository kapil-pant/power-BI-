# Tools and Techniques
# Power BI Features Used:
* Dynamic Titles: Automatically update based on filters applied.
* DAX Measures:
* Total Income = SUM(Income)
* Total Savings = SUM(Savings)
* Growth Percentage = DIVIDE(Current Year, Previous Year, 0) - 1
* Custom Measures for KPI analysis.
* Drill-through and slicers for enhanced interactivity.
* 
# Visualization Tools:
* KPI Cards for tracking financial health.
* Line and bar charts for trend analysis.
* Donut and pie charts for category-wise expenditure.
